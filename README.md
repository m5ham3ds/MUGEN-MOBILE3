# Phase 12 — Release and Build Instructions

## Building from source (Android / Termux / Code Assist)

Since MUGEN Mobile heavily relies on `IKEMEN GO` as its core engine, building the application from source involves preparing the native engine libraries first.

### Step 1: Prepare Ikemen-GO Native Library
1. You must compile `libikemen.so` for your target architecture (e.g. `arm64-v8a`). This requires a Go environment and Android NDK (r27d recommended).
2. The recommended official way is to use Docker on a PC as mentioned in the Ikemen-GO `BUILDING.md`:
   `bash build_docker.sh android`
3. Alternatively, for building on-device, you can set up `gomobile` in Termux, clone `JeusZilla/ikemen-droid`, compile the `.so` files, and place them inside `app/src/main/jniLibs/arm64-v8a/`.

### Step 2: Prepare Engine Assets
The core IKEMEN GO engine requires default assets (like screenpacks, fonts, etc.) to run. 
Place all these core engine files in the `/app/src/main/assets/` directory before building the APK.

### Step 3: Build the Android APK
Once the `jniLibs` and `assets` are in place, you can build the Android wrapper (MUGEN Mobile) which we have created.

**From Code Assist / Termux:**
Run the following Gradle command in the root of the project:
`./gradlew assembleDebug` (For Debug APK)
or
`./gradlew assembleRelease` (For Release APK)

### Notes on the Android App (MUGEN Mobile)
- **Architecture**: The app uses Kotlin, Jetpack Compose, Room Database (for the Game Library), and DataStore (for settings/onboarding).
- **Game Import**: Users do not need to place their games in the APK. The app uses the Android Storage Access Framework (SAF). Users click `+` on the home screen to select a game folder from their internal storage or SD Card.
- **Mod Manager**: Characters and Stages are automatically scanned and can be enabled/disabled non-destructively from the Game Details screen.
- **Controller**: A customizable touch controller is built-in (`ControllerEditorScreen`), allowing you to position buttons anywhere on the screen.
